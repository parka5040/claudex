# Claude Code 2.1.302 + Codex 0.163.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run claudex correctly on Claude Code 2.1.302 and codex-cli 0.163.0, and make GPT agents
visible the way native agents are: the resolved GPT model in `/tasks`, and a live claudex status
line.

**Architecture:** Four independent tasks.
- **Task 1, proxy (C):** matches the 0.163.0 Codex client's request and stream semantics.
- **Task 2, mod (TS + worker bash):** updates agent lifecycle and labels for 2.1.302.
- **Task 3, tooling:** updates the type check, tool schemas and live checks.
- **Task 4, docs and version:** lands after 1–3.

Tasks 1–3 touch disjoint files and may run in parallel.

**Tech Stack:**
- Proxy: C17, yyjson, libcurl; unit tests in `tests/unit/*_test.c` (`make test`, ASan+UBSan).
- Mod: hooks module in TypeScript on the Claude Code Mods API; tests in `plugin/tests/*.test.ts`
  (`claude plugin test plugin`).
- Worker: bash `plugin/bin/claudex-worker`; tests in `tests/worker/*.sh`.

**Spec:** `docs/superpowers/specs/2026-10-18-cc-2.1.302-codex-0.163-design.md` (read it first; this
plan argues from it).
