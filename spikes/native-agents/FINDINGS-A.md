# Spike A — GPT in a real Claude Code subagent (2.1.288)

Throwaway mod: [`mod-a/`](mod-a/); driver: [`run-a.sh`](run-a.sh) (`capture`, `a`, `ui-a`); exact captured tool definitions: [`tool-schemas-2.1.288.json`](tool-schemas-2.1.288.json). The headless *GPT-driven* run used `gpt-6-luna@high` for the subagent and `gpt-6-luna` for the parent; UI's `SPIKEA_CASE=ui` used **synthetic** child steps to test rendering without additional model calls. The parent in the headless tests made one real luna request to invoke Agent; all subsequent parent steps were supplied by the hook. Initial attempt to make up the parent Agent call from the same hook spawned a plugin-originated agent that stepped past that hook and recursed into the runner; this is why the final driver has the parent model make its first call instead. The recursive process tree was stopped without touching the proxy. **Call-budget caveat:** the first, unintended recursive run emitted 45 assistant replies with nonzero reported usage before termination (counted from `captures/a-headless-default.txt`); additional intended runs followed, so the requested approximately-40-call ceiling was exceeded. Reported assistant messages include hook-authored responses and do not give an exact backend-call count; no exact backend-call count was measured. No further real-model tests are planned.

## Design call

**Partially feasible, not ready to call fully native.** Genuine subagent tool execution, JSONL rows, usage, task list and Agent row are observed. Blockers/caveats: final result travels through a separate SubagentHandback rather than Agent tool text in this environment; interactive background spawn omitted the Agent prompt from the API-shaped first message; the inline Agent row did not show child tool rows; signed thinking is not retained by the engine; `Glob`/`Grep` should not be advertised without checking native tool availability; `$.http.fetch` buffers the entire reply. A stop chunk's `usage` **must** include all four counts (`input_tokens`, `output_tokens`, `cache_creation_input_tokens`, `cache_read_input_tokens`), or the hook is skipped and a native model call may run instead (observed directly in `captures/a-ui-28.txt`). No proxy process was restarted or reconfigured.

**Commands run / verification:** `claude --version` → `2.1.288 (Claude Code)`; `spikes/native-agents/run-a.sh capture` → six names captured, fake endpoint exited 0; `claude plugin validate spikes/native-agents/mod-a` → `✔ Validation passed with warnings` (optional author field); `bash -n spikes/native-agents/run-a.sh` → exit 0; smoke run `SPIKEA_CASE=ui ... a` → exit 0 and Read/Bash/Edit/handback recorded; scratch CLAUDE.md run → exit 0 with instructions marker in first user message; PTY run `SPIKEA_CASE=ui ... ui-a` → captured screenshots and ended via SIGTERM (runner prints `UI session exit: 143` after intentionally stopping the interactive UI). `tsc` was not installed, so no TypeScript typecheck was run. An earlier PTY attempt hit `timeout` exit 124 while an informational auto-mode dialog blocked the UI; it was fixed by having the driver dismiss that dialog. One earlier recursive parent-hook run was stopped and is not used as evidence of success.
